# 基础设备信息

`GET /device` 只读取本机型号、主机名、系统名称与版本、架构，以及非回环网卡的名称、IP、子网掩码和 MAC；结果缓存 30 秒。系统未提供的型号显示未知，macOS 使用系统给出的型号标识，例如 `Mac15,12`。

同一份信息附在 `/manifest` 的 `metadata.device` 和 `/nodes` 的本机条目中，协议为 `dreammate.device.v1`。`/health` 通过 `device_info` 声明支持，新版 MCP/CLI 仅对支持的节点读取此信息；旧版节点保留原有行为。

可视化页面在原有设备详情中展示基本信息，本地网卡默认折叠。不会发送节点间探测请求，也没有新增的路由/邻居查询、同局域网判断或设备分组。原有设备发现、网关探活及 Tailscale 路径展示保持原有逻辑。设备地址簿仍只保存稳定地址，不导出这些实时信息。
